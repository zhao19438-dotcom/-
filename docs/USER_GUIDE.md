# 用户手册

本手册介绍校园论坛各项功能的日常使用方法。前台入口：`http://localhost:5173`（开发）或生产环境 Nginx 地址。

## 1. 注册与登录

### 注册新账号

1. 点击首页右上角「注册」，进入学籍认证页
2. 填写用户名、密码、学号、真实姓名、学院、班级等信息；注册后可在账号设置中设置密保问题和答案
3. 完成图形验证码后提交，注册成功自动跳转登录

### 登录

- 支持用户名登录，连续失败会触发限流保护，请稍后再试
- 登录页填写本人账号和密码，不提供快捷测试入口

### 找回密码

1. 登录页点击「忘记密码」
2. 第一步：输入用户名，系统展示你的密保问题
3. 第二步：回答密保问题，验证通过后设置新密码

### 退出登录

右上角头像浮层 →「退出」。

## 2. 浏览与搜索

- **首页**：顶部导航、版块筛选和讨论列表，右侧为个人入口及热门讨论
- **版块筛选**：点击版块切换，支持最新/热门排序；筛选和页码保存在网址中
- **搜索**：顶部搜索框输入关键字回车，按标题与正文全文检索
- **帖子详情**：进入帖子查看完整 Markdown 正文；失物招领帖会展示专属登记卡片（物品、地点、联系方式）

## 3. 发帖

1. 登录后点击「发帖」按钮
2. 选择版块；当选择「失物招领」版块时，会出现扩展表单（类型：失物/招领、物品名称、地点、联系方式）
3. 正文支持 Markdown，可切换「编辑 / 预览」实时查看渲染效果
4. 提交后自动跳转到帖子详情

> 发帖内容会经过敏感词过滤，包含违禁词的帖子将被拒绝或替换，请遵守校园网络公约。

## 4. 互动

- **点赞**：帖子详情页点赞/取消点赞，计数实时更新
- **收藏**：收藏帖子后可在「我的收藏」查看，支持分页及取消收藏
- **回复**：详情页底部发表回复；点击某条回复的「回复」按钮可发起楼中楼嵌套回复（支持两级）
- **举报**：帖子右侧菜单选择「举报」，填写理由提交，管理员将在后台核查处置

## 5. 私信与通知

通过顶部消息图标或头像菜单进入「消息中心」，包含四个标签页：

| 标签 | 内容 |
| :--- | :--- |
| 收件箱 | 收到的私信，未读有气泡提醒，可就地回复、举报、拉黑 |
| 发件箱 | 已发送的私信 |
| 系统通知 | 系统与管理员发送的通知（如举报处置结果、帖子被点赞/收藏/回复提醒） |
| 黑名单管理 | 查看已拉黑用户并可解除拉黑 |

- **快捷发私信**：在帖子详情页的交流区，点击任意回复者的头像，在弹出菜单中选择「发私信」，直接输入内容发送；也可选择「查看主页」跳转
- **一条未回复限制**：给某人发送私信后，在对方回复之前不能再发送第二条（防止骚扰），对方回复后即可继续
- **举报私信**：在收件箱中对某条私信点击「举报TA」，选择违规类型并提交，管理员将在后台核查处置
- **拉黑用户**：在收件箱中对某条私信点击「拉黑TA」并确认，此后对方无法再向你发送私信；可在「黑名单管理」标签页随时解除
- 发私信：在对方主页或详情页点击「私信」，或从消息页发起
- 顶栏的未读红点每 30 秒自动轮询刷新

## 6. 个人中心

### 我的主页（Profile）

- 展示头像、学院/班级/学号微标、发帖与收藏统计
- 选项卡切换「TA 的帖子 / 我的收藏」

### 设置（Settings）

分三个模块：

| 模块 | 功能 |
| :--- | :--- |
| 基本资料 | 修改昵称、性别、学院、班级、个人简介 |
| 密保设置 | 修改密保问题与答案 |
| 登录密码 | 输入旧密码设置新密码 |

- 头像：点击头像上传新图片，支持 jpg/png，自动裁剪展示，保存后即时生效

## 7. 管理后台（仅管理员）

以 `admin` 登录后，左侧出现「管理后台」入口，深翠色控制台包含 7 个模块：

| 模块 | 功能 |
| :--- | :--- |
| 数据大盘 | 用户数、版块数、帖子数总览统计 |
| 用户管理 | 搜索学生、封禁/解封、设/撤管理员、重置密码、注销账号 |
| 版块管理 | 新增/编辑版块、启用停用、删除 |
| 帖子管理 | 按版块/关键字检索，禁用/恢复、删除、置顶、加精 |
| 敏感词管理 | 增删敏感词，保存后即时刷新过滤缓存 |
| 举报处理 | 查看举报列表并处置（处理结果会通知举报人） |
| 审计日志 | 检索登录、管理操作等审计记录（含 IP） |

## 8. 常见问题

| 问题 | 处理 |
| :--- | :--- |
| 登录提示验证码错误 | 验证码一次性有效，刷新后重新输入即可 |
| 操作提示「缺少防伪请求头」 | 请勿用脚本直接调用接口，正常浏览器操作不受影响 |
| 请求过于频繁被限制 | 触发限流保护，等待约 1 分钟后再操作 |
| 忘记密保答案 | 联系管理员在后台重置密码 |
| 头像上传失败 | 确认图片为 jpg/png 且大小未超限 |
| 页面 404 | 使用顶部导航或浏览器后退，如始终异常请联系管理员 |
